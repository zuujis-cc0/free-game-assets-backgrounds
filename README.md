# Parallax backgrounds: Zuujis free game assets

Six layered parallax scenes, clouds and a scene index. Public-domain **CC0**: use them in commercial or personal games. Credit is optional.

Every file is here on its own: open one on GitHub and use **Download raw file** to save just that file. Or download the whole pack:
